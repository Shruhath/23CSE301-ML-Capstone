# 23CSE301 Machine Learning Capstone

Repository for the 2026-27 Machine Learning capstone project.

The project is organized into three end-to-end tracks:

- Regression
- Classification
- Clustering

## Repository structure

```text
app/                 Optional GUI and deployment code
data/                Dataset notes and raw assigned data
figures/             Generated visualizations
models/              Saved final pipelines
notebooks/           Regression, classification, and clustering notebooks
results/             Exported metric tables
```

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
